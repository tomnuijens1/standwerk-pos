# Standwerk POS

Kassasysteem en voorraadbeheer voor merchandise op festivals, tours en evenementen.

## Inhoud van deze map
- `CLAUDE.md`: projectinstructies voor Claude Code (wordt automatisch gelezen)
- `prototype/standwerk-pos.html`: werkend prototype, open het in een browser
- `docs/`: specificatie, datamodel, roadmap, betaalterminals en design
- `voorbeelden/`: Excel-importsjabloon en een voorbeeldassortiment

## Starten met Claude Code
Open deze map in Claude Code en begin bijvoorbeeld met:

> Lees CLAUDE.md en de docs, bekijk het prototype en stel een technisch plan voor fase 1 voor.

## Prototype bekijken
Dubbelklik op `prototype/standwerk-pos.html`. Er is internet nodig voor lettertypen, Excel en grafieken. Gegevens blijven lokaal in je browser. Ga naar Instellingen en klik op Voorbeelddata laden om alles gevuld te zien.
